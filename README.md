\# Task 3: SQL for Data Analysis



\## Project Overview



This project demonstrates SQL techniques for extracting and analyzing data from an e-commerce database using MySQL.



\## Objective



The objective of this task is to use SQL queries to extract, manipulate, and analyze structured e-commerce data.



\## Tools Used



\* MySQL

\* MySQL Workbench

\* GitHub



\## Dataset



An e-commerce SQL dataset was imported into MySQL. The database contains tables related to customers, orders, order items, payments, and categories.



\## SQL Concepts Covered



\* SELECT

\* WHERE

\* ORDER BY

\* GROUP BY

\* Aggregate Functions: COUNT, SUM, AVG, MAX

\* INNER JOIN

\* LEFT JOIN

\* RIGHT JOIN

\* Subqueries

\* SQL Views

\* Indexing

\* Query Optimization using EXPLAIN



\## Analysis Performed



1\. Filtered customers based on loyalty points.

2\. Analyzed orders by status and calculated revenue and average order value.

3\. Joined customers with their orders using INNER JOIN.

4\. Used LEFT JOIN to analyze customers and their orders.

5\. Joined orders with payment information using RIGHT JOIN.

6\. Used a subquery to identify orders above the average order value.

7\. Identified the highest-value order using a subquery.

8\. Created a view for customer order analysis.

9\. Created an index and used EXPLAIN for query optimization.

10\. Analyzed total orders, revenue, and average order value by customer.



\## Deliverables



\* `ecommerce\_sql\_analysis.sql` — SQL queries used for the analysis.

\* `screenshots/` — Screenshots showing SQL queries and their outputs.



\## Conclusion



The project demonstrates how SQL can be used to query, join, aggregate, and analyze structured e-commerce data for data analysis purposes.
